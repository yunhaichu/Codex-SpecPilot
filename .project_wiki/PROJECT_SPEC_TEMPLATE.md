# Project Specification Template
## 1. Project Goal
写清楚这个项目最终要实现什么。
## 2. Background
写清楚为什么要做这个项目、当前已有基础是什么。
## 3. User Requirements
逐条列出用户确认过的需求。
## 4. Non-Goals
写清楚明确不做什么。
## 5. Allowed Scope
写清楚 Codex 允许修改哪些目录、哪些文件、哪些类型的内容。
## 6. Protected Scope
写清楚 Codex 不允许修改哪些目录、哪些文件、哪些内容。
## 7. Development Plan
把开发任务拆成步骤。
## 8. Acceptance Criteria
写清楚什么情况下算完成。
## 9. Stop Conditions
写清楚什么情况下必须停止并要求人工确认。
## 10. Submission Requirements
写清楚完成后要提交什么结果、运行什么测试、写什么报告。
